## 4. BAT 자동 실행 흐름

`RunBomberSystemQA.bat`은 다음 단계를 순서대로 수행한다.

1. 실행 중인 Unreal Editor와 실행 환경을 확인한다.
2. Unreal Editor 명령형 실행으로 `Bomber.System.` 테스트 그룹을 실행한다.
3. 실행별 새 Automation 보고서를 생성하고 `index.json` 결과를 검사한다.
4. 테스트 ID, 자동화 경로, 오류 수를 검증해 Pass, Fail, Blocked 상태를 판정한다.
5. 검증된 결과를 Google Sheets의 `시스템 테스트 케이스` 탭에 기록하고 다시 읽어 반영 여부를 확인한다.
6. 실패 항목이 있으면 동일 테스트 ID의 열린 Jira 이슈를 검색한다.
7. 기존 이슈가 있으면 재발 댓글을 추가하고, 없으면 새 버그 이슈를 생성한다.
8. 성공·실패 수와 Jira 처리 결과를 Slack으로 항상 알린다.

따라서 정상 운영용 BAT 하나만 실행하면 시스템 테스트와 외부 도구 기록이 끝난다. 의도적 실패 BAT는 Jira 실패 흐름을 시연하거나 재검증할 때만 별도로 사용한다.
